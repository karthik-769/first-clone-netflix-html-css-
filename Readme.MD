# 🎬 Netflix Clone (HTML & CSS Only)

A simple **Netflix landing page clone** built using **only HTML and CSS** — no JavaScript, no frameworks.  
This project is for learning web design, layout techniques, and responsive styling.

---

## 🚀 Project Overview

This project recreates the **visual layout** of the Netflix homepage.  
It focuses on practicing:
- Semantic HTML structure
- Flexbox and CSS Grid layouts
- CSS transitions & hover effects


🧠 **Goal:** To understand how professional websites are structured and styled without relying on JavaScript.

---

## 🧰 Tech Stack

| Technology | Purpose |
|-------------|----------|
| HTML5 | Page structure |
| CSS3 | Styling and responsiveness |
| Flexbox & Grid | Layout handling |


---

## 🌟 Features

- ✅ Netflix-style layout  
- ✅ Hero banner with overlay  
- ✅ Navigation bar with logo and buttons  
- ✅ Movie/Show cards grid  
- ✅ Hover effects using CSS only  
- ✅ Footer section  
- ✅ Fully static and lightweight
